# Florent's style

When Florent corrects something that isn't here, add one line under **Learned**, in his words.

- No comments in code; rename or split instead. A docstring only when one line and needed.
- Small, direct functions. No abstraction for one use, no dead code, no unused options.
- Follow the file you are in: naming, patterns, error handling.
- Errors reach the person, never swallowed.
- Tests next to what they test, on behavior.
